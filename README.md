# Music Playlist Using Linked List in C

## Project Description
The Music Playlist Management System is a simple menu-driven application developed using the C programming language and Doubly Linked List data structure.

It allows users to manage their music playlists by adding, deleting, searching, and navigating between songs.

## Features
- Add new songs to the playlist.
- Display all songs.
- Delete songs from the playlist.
- Search for a particular song.
- Play the current song (simulation).
- Navigate to the next song.
- Navigate to the previous song.
- Count the total number of songs.

## Technologies Used
- C Programming Language
- Data Structures
- Doubly Linked List
- Dynamic Memory Allocation
- Pointers and Structures

## Data Structure Used
A Doubly Linked List is used to store songs. Each node contains:
- Song name
- Pointer to the next song
- Pointer to the previous song

This allows navigation in both forward and backward directions.

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the program:

```bash
gcc music_playlist.c -o music_playlist
```

5. Run the program on Windows:

```bash
.\music_playlist.exe
```
